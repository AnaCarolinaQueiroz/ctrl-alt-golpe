# Ctrl+Alt+Golpe

Detector de golpes e phishing para mensagens em português, feito para o Hack Brasil 2026 (trilha Cibersegurança).

> Projeto em construção.

## O problema
Golpes por mensagem (falsos avisos de entrega, Pix e bancos) chegam todos os dias. Muita gente não tem como conferir rapidamente se uma mensagem é segura.

## A ideia
O usuário cola uma mensagem ou link suspeito e recebe um nível de risco, os sinais que levantaram o alerta e o que fazer em seguida. O código, as fontes de dados e o método de avaliação serão públicos neste repositório.

## Aviso
Esta ferramenta é um apoio, não uma garantia. Na dúvida, confirme pelo canal oficial da empresa.
